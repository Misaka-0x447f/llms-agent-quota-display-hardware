Antigravity 额度行 + plan 徽标 — 目标体验草案

OLED 区域按 128×64、3 倍放大绘制（1 个 7×14 字格 = 21×42 px，位置即固件里的真实像素坐标 ×3）。 这是待确认的目标草案，不是已实现效果。窗口行统一 7×14 字体；余额行不受影响。

徽标规则（已确认）

· 只有「订阅/窗口行」（chatgpt / claude / antigravity）带徽标，余额行（deepseek / openrouter）不带。

· 字母按厂商取：ChatGPT → [O]（OpenAI）、Antigravity → [G]（Google / Gemini）、Claude → [A]（Anthropic）。

· 反色显示：9×12 的实心块，字母镂空，压在重置倒计时左侧、共占 13px（9 块 + 4 间隔）。方块本身就是“反色”，不是打出来的方括号。

· 位置固定在最左边 x=0，重置时间整体右移 13px；Δ 与百分比的相对布局不变。

Antigravity 行（已确认）

· 来源写成 antigravity（只接受 7d，不接受 :5h），显示 Gemini 的每周额度。

· 剩余额度 > 0 时：[G] [5d] Δ+1h 63%，与其他窗口行一致。

· 剩余额度 = 0%，或充值余额低于 minimumCreditAmountForUsage 时：丢掉 Δ，右侧改显示充值余额 [G] [5d] 0% 12.34。余额 = credits ÷ 100，两位小数，不带 $。

· 0% 但接口没给充值余额（非 Pro/Ultra 或字段缺失）：右侧显示 --，不拿 0.00 冒充。
